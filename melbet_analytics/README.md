# Melbet Account Analytics System

This directory contains the codebase for the automated Melbet account data extraction and analytics system.

## Setup Instructions

1. Set this directory as your active workspace in your editor (e.g., File -> Open Folder in VS Code).
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   playwright install chromium
   ```
3. Configure the `.env` file with your credentials and configuration settings.
4. Run the application:
   ```bash
   python main.py
   ```
